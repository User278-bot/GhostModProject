# Ghost Mod Project

日本語版:
[README.md](README.md)

**Ghost Mod** is a Minecraft Mod and server software designed to simulate multiplayer functionality in single-player adventure maps.

It synchronizes each player's position in real-time and displays them as a "ghost" on other players' clients.
These ghosts are client-side entities only and do not interfere with server-side logic (such as command blocks or damage calculation). This allows you to explore maps with friends without breaking any map mechanics.

> [!NOTE]
> This project is developed using **Antigravity** and **Google AI Studio**, with the majority of the code generated by AI.

## Project Structure
This project consists of the following modules:

- **ghost-mod**: The main Minecraft Mod (Fabric). Supports multiple versions using Stonecutter.
- **ghost-server**: A relay server for synchronization (Java Application).
- **ghost-fake_client**: A dummy client for load testing and debugging.
- **ghost-api**: Common packet definitions and data structures.

## Installation

### 1. Mod Installation (Client)
1.  Place `ghostmod-<version>+<mc_version>.jar` into your Minecraft `mods` folder.
2.  Install the following mods matching your Minecraft version:
    - **Required**
        - [Fabric API](https://modrinth.com/mod/fabric-api)
        - [Cloth Config API](https://modrinth.com/mod/cloth-config)
    - **Optional**
        - [Mod Menu](https://modrinth.com/mod/modmenu)

### 2. Starting the Server
Run `GhostModServer-<version>.jar` to start the synchronization server.

```bash
java -jar GhostModServer-<vesion>.jar
```
By default, it listens on port `8887`. Use the `--port` option to change the port.

```bash
java -jar GhostModServer-<vesion>.jar --port 9000 --password <password> --config <filename> --view-distance <distance> --rate-limit <rate>
```

Other options can be found with `--help`.
```bash
java -jar GhostModServer-<vesion>.jar --help
```

> [!IMPORTANT]
> For non-LAN play (e.g., playing with distant friends), you must expose the server to the internet.
>
> - **Port Forwarding**: Open port `8887` (or your specified port) in your router settings. Please manage security settings at your own risk.
> - **If Port Forwarding is difficult**: You can use the following services to connect without opening ports:
>     - [Fast Server](https://fss.zpw.jp/) **ConnectXross** (Recommended/Verified): Requires settings only on the server side, easiest for the connecting side (your friends).
>     - [playit.gg](https://playit.gg/): A tunneling service similar to ConnectXross, no client-side config needed.
>     - [Hamachi](https://www.vpn.net/): Virtual LAN service. Everyone must install the software and join the same network.

## Usage
1.  Start the server (on your PC for local play, or on a VPS/etc. for distant play).
2.  Launch Minecraft with the Mod installed.
3.  Open the **Ghost Mod** settings screen via Mod Menu or using the shortcut key (default: G key).
4.  Enter the server address, port, and password, then save.

![Minecraft_ 1 19 2 2025_12_07 15_25_20](https://github.com/user-attachments/assets/6b8b27db-694b-4c3d-bd01-b5a3b891d6a7)
![Minecraft_ 1 20 1 2025_12_21 8_51_29](https://github.com/user-attachments/assets/00ecd29f-e7f0-49da-a643-8b6072ca7cdf)

5.  Enter a single-player world, and you will **automatically** connect to the server.
6.  Other players connected to the same server will appear as ghosts in your world.

> [!NOTE]
> Connect and Disconnect buttons are enabled while in a single-player world. Use them as needed.

## Developer Information
### Build Instructions
Run the following command in the project root directory:

```bash
./gradlew build
```

### Output Location

Upon a successful build, artifacts (JAR files) are generated in the following locations:

#### Mod (ghost-mod)
Output to the following directories per version:
- `ghost-mod/versions/1.19.2/build/libs/ghostmod-<vesion>+1.19.2.jar`
- `ghost-mod/versions/1.20.1/build/libs/ghostmod-<vesion>+1.20.1.jar`
etc.

#### Server (ghost-server)
- `ghost-server/build/libs/GhostModServer-<version>.jar`
※ `GhostModServer-*.jar` (the larger file) is the executable server application.

### FakeClient
`FakeClient` is provided to send dummy player data for load testing and synchronization checks.

```bash
./gradlew :ghost-fake_client:run --args="--uuid <UUID> --uri <URI> --password <password>"
```

### Starting Debug Environment
You can launch the server, client, and FakeClient all at once using the PowerShell script.

```powershell
# Start debug environment
.\start-debug.ps1

# Stop debug environment
.\stop-debug.ps1
```
